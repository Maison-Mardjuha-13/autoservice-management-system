# AutoService Management System

## Система управления техническим обслуживанием автомобилей

Учебный PET-проект системного и бизнес-аналитика, посвящённый анализу,
реинжинирингу и проектированию информационной системы для автоматизации
процесса технического обслуживания автомобилей.

---

## 📌 О проекте

Проект представляет собой комплексное исследование и проектирование
информационной системы, предназначенной для автоматизации процесса
технического обслуживания автомобилей в сети автосервисов.

В основе проекта лежит исследование предметной области, анализ текущего
бизнес-процесса (AS-IS), выявление проблем и разработка целевого процесса
(TO-BE), проведенные в рамках **курсовой работы**.

Проект демонстрирует полный цикл работы системного и бизнес-аналитика:

**анализ предметной области → моделирование бизнес-процессов →
выявление проблем → формирование требований → проектирование системы →
описание API и базы данных → прототипирование → тестирование.**

---

## 🎯 Цель проекта

Разработать концепцию и прототип информационной системы, позволяющей
автоматизировать основные операции процесса технического обслуживания
автомобилей, сократить количество ручных операций и повысить прозрачность
выполнения заказов.

---

## 💼 Бизнес-проблема

Процесс технического обслуживания автомобиля включает большое количество
операций, выполняемых различными сотрудниками сервисного центра.

При использовании разрозненных информационных систем и ручной обработки
части данных могут возникать следующие проблемы:

- дублирование информации;
- большое количество ручных операций;
- повторный ввод данных;
- сложности при контроле состояния заказа;
- проблемы с проверкой наличия необходимых запчастей;
- дополнительные согласования с клиентом;
- отсутствие единого информационного пространства;
- увеличение времени выполнения процесса;
- зависимость от человеческого фактора.

---

## 💡 Предлагаемое решение

В рамках проекта проектируется единая информационная система, которая
обеспечивает управление основными этапами технического обслуживания:

1. Приём заявки клиента.
2. Проверка информации об автомобиле.
3. Планирование обслуживания.
4. Проверка доступности необходимых ресурсов и запчастей.
5. Приём автомобиля в сервис.
6. Диагностика автомобиля.
7. Формирование перечня работ.
8. Согласование дополнительных работ с клиентом.
9. Выполнение технического обслуживания.
10. Контроль качества.
11. Формирование итоговой документации.
12. Уведомление клиента.
13. Передача автомобиля клиенту.
14. Закрытие заказа.

## 👥 Пользователи системы

### Клиент

- создание заявки;
- выбор автомобиля;
- запись на обслуживание;
- просмотр статуса заказа;
- согласование дополнительных работ;
- просмотр истории обслуживания.

### Сервисный консультант

- обработка заявок;
- взаимодействие с клиентом;
- планирование обслуживания;
- оформление заказа;
- согласование работ.

### Мастер-приёмщик

- приём автомобиля;
- формирование перечня работ;
- контроль наличия запчастей;
- управление заказом;
- взаимодействие с автомеханиками.

### Автомеханик

- проведение диагностики;
- выполнение работ;
- заполнение чек-листов;
- фиксация результатов обслуживания.

### Руководитель

- контроль выполнения заказов;
- анализ показателей процесса;
- просмотр статистики;
- контроль загрузки сервисного центра.

## 📊 Аналитическая часть

В рамках проекта выполняется анализ бизнес-процесса:

### AS-IS

Исследование существующего процесса и выявление:

- узких мест;
- дублирования операций;
- избыточных действий;
- ручных операций;
- проблем взаимодействия между участниками;
- проблем информационного обмена.

### TO-BE

Проектирование целевого процесса с учётом:

- автоматизации операций;
- сокращения ручного труда;
- устранения дублирования информации;
- улучшения взаимодействия сотрудников;
- повышения прозрачности процесса;
- автоматизации работы с заявками и заказами.
