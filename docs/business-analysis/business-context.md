# Бизнес-контекст системы

## Система

AutoService Management System (ASMS)

## Внешние участники

- Клиент
- Сервисный консультант
- Мастер-приёмщик
- Автомеханик
- Руководитель сервисного центра

## Внешние системы

### ERP

Используется для получения информации о наличии запчастей
и взаимодействия с учётной системой.

### Notification Service

Используется для отправки уведомлений клиенту.

## Основные информационные потоки

Клиент → ASMS:
- данные заявки;
- данные автомобиля;
- подтверждение дополнительных работ.

ASMS → Клиент:
- подтверждение записи;
- статус заказа;
- информация о дополнительных работах.

ASMS → ERP:
- запрос информации о запчастях;
- запрос резервирования.

ERP → ASMS:
- информация об остатках;
- результат резервирования.

ASMS → Notification Service:
- сообщение для клиента.
