# Бизнес-правила

| ID | Правило |
|---|---|
| BR-001 | Каждый автомобиль должен быть связан с клиентом |
| BR-002 | VIN автомобиля должен быть уникальным |
| BR-003 | Заявка не может быть создана без клиента и автомобиля |
| BR-004 | Запись возможна только при наличии свободного временного интервала |
| BR-005 | Для одного автомобиля не допускаются две активные записи на одно время |
| BR-006 | Перед началом работ должна быть проверена доступность необходимых запчастей |
| BR-007 | Дополнительные работы, отсутствующие в первоначальном заказе, должны быть согласованы с клиентом |
| BR-008 | После отказа клиента дополнительные работы не должны выполняться |
| BR-009 | Заказ не может быть закрыт до завершения обязательных работ |
| BR-010 | Перед выдачей автомобиля должен быть выполнен контроль качества |
| BR-011 | Автомобиль может быть выдан только после оформления итоговой документации |
| BR-012 | Все изменения критически важных данных должны фиксироваться в журнале аудита |
| BR-013 | Доступ к функциям системы определяется ролью пользователя |
| BR-014 | После готовности автомобиля клиент должен получить уведомление |
