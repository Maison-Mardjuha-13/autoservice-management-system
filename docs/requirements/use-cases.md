## UC-001 — Создание заявки

**Актор:** Сервисный консультант

**Цель:** Создать заявку на техническое обслуживание.

**Предусловия:**
- клиент существует;
- автомобиль зарегистрирован в системе.

**Основной сценарий:**

1. Сотрудник открывает форму создания заявки.
2. Выбирает клиента.
3. Выбирает автомобиль.
4. Выбирает услугу.
5. Указывает желаемую дату и время.
6. Система проверяет корректность данных.
7. Система проверяет доступность времени.
8. Система создаёт заявку.
9. Система присваивает заявке статус `NEW`.

**Альтернативные сценарии:**

- Если обязательные данные не заполнены — система отображает ошибку.
- Если выбранное время занято — система предлагает другой интервал.

**Результат:**

Заявка создана и доступна сотрудникам сервисного центра.
