# Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-001 | Время ответа системы на стандартные операции не должно превышать 2 секунд |
| NFR-002 | Система должна обеспечивать доступность не менее 99% времени |
| NFR-003 | Передача данных должна выполняться по защищённому протоколу HTTPS |
| NFR-004 | Доступ к функциям системы должен определяться ролью пользователя |
| NFR-005 | Пароли пользователей не должны храниться в открытом виде |
| NFR-006 | Система должна регулярно создавать резервные копии базы данных |
| NFR-007 | Система должна вести журналирование критически важных операций |
| NFR-008 | Архитектура системы должна позволять добавлять новые сервисные центры |
| NFR-009 | Система должна предоставлять REST API для интеграции с внешними системами |
| NFR-010 | Интерфейс системы должен быть понятным и единообразным для пользователей |
