# Функциональные требования

| ID | Требование | Приоритет |
|---|---|---|
| FR-001 | Система должна позволять создавать и редактировать карточку клиента | Must |
| FR-002 | Система должна позволять добавлять автомобиль к клиенту | Must |
| FR-003 | Система должна позволять создавать заявку на техническое обслуживание | Must |
| FR-004 | Система должна проверять доступность времени для записи | Must |
| FR-005 | Система должна позволять создавать электронный заказ-наряд | Must |
| FR-006 | Система должна позволять фиксировать результаты диагностики | Must |
| FR-007 | Система должна позволять добавлять работы и запчасти в заказ-наряд | Must |
| FR-008 | Система должна проверять наличие необходимых запчастей | Must |
| FR-009 | Система должна позволять согласовывать дополнительные работы с клиентом | Must |
| FR-010 | Система должна позволять изменять статус заказа | Must |
| FR-011 | Система должна предоставлять электронный чек-лист контроля качества | Should |
| FR-012 | Система должна уведомлять клиента об изменении статуса заказа | Should |
| FR-013 | Система должна хранить историю обслуживания автомобиля | Must |
| FR-014 | Система должна предоставлять отчёты руководителю сервисного центра | Should |
| FR-015 | Система должна поддерживать разграничение доступа по ролям | Must |
